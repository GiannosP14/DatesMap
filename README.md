## ✨ What It Includes
* **Hero section:** A customizable headline, subtitle, and call to action.
* **Interactive map:** A Leaflet.js map with custom heart markers for each memory.
* **Event list:** Clickable list entries that automatically pan the map to each location and open its popup.
* **Future adventures:** A card grid for planned dates or bucket-list items.
* **Surprise modal:** A reusable reveal panel for a message, proposal, or invite.
* **Fully Responsive:** Designed to look great on phones, tablets, and desktop screens.

## 🚀 Quick Start Guide
You don't need a backend or a build step for this project.

1. Clone or download this repository.
2. Open `index.html` in your browser to view it locally.
3. Open `index.html` in your code editor and scroll down to the **`siteConfig`** object (around line 180).
4. Replace the placeholder text, coordinates (`lat`, `lng`), and dates with your own story.
5. Host it for free in seconds by dragging the folder into [Netlify Drop](https://app.netlify.com/drop) or using GitHub Pages.

## 🛠️ Customization Notes
The main content lives inside the `siteConfig` object near the bottom of `index.html`.
* `dateSpots`: Requires `lat`, `lng`, `title`, `date`, and `description`. To add photos to map popups, simply add an image tag directly into the description string.
* `futureDates`: Uses `activity`, `reason_missed`, `proposed_date`, and `locked_in`.
